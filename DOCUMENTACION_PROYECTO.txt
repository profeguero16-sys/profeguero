1. RESUMEN EJECUTIVO DEL PROYECTO
================================================================================

ProfeGüero es una plataforma web moderna y responsiva diseñada para la formación
profesional en voleibol. El sitio funciona como catálogo de servicios, vitrina
de cursos, testimonios de estudiantes, campamentos y materiales deportivos.

La plataforma está optimizada para:
- Conversión de visitantes en clientes
- Experiencia mobile-first
- Integración directa con WhatsApp para consultas
- Carga rápida y SEO amigable

10. PERFORMANCE Y OPTIMIZACIONES

A. BUILD OPTIMIZATION
   ─────────────────────────────────────────────────────────────────────────
   
   Vite:
   • Code splitting automático
   • Tree-shaking de módulos no usados

   • Source maps en dev, sin source maps en prod
   
   CSS Purging:
   • Tailwind CSS: Purga automática de clases no usadas
   • Resultado: CSS < 50KB gzipped (típico)
   
   Scripts: Los build scripts están centralizados en package.json


B. RECURSOS ESTÁTICOS
   ─────────────────────────────────────────────────────────────────────────
   
   Imágenes:
   • Lazy loading: loading="lazy" en <img>
   • Placeholder: DummyImage services (placehold.co)
   • Imagen real: aboutMeProfeGuero.jpeg en assets
   
   Fonts:
   • Preconectadas: <link rel="preconnect" href="fonts.googleapis.com" />
   • Descarga: Woff2 (formato optimizado)
   • Display: swap (muestra fallback mientras carga)

   • FCP (First Contentful Paint): < 2 segundos
   • LCP (Largest Contentful Paint): < 2.5 segundos
